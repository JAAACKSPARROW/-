# 肽序列机器学习论文复现

把原始序列、特征、清洗、训练和评估连接成可追溯的计算流程。报告实际执行结果，区分论文声称的成绩、作者代码的行为、历史 Notebook 输出和独立重建结果。

## 先确定当前任务

- **首次完整复现**：阅读 [计算流程](references/workflow.md)，按论文和作者代码建立实验协议，再执行。
- **已有项目再次运行**：保留已有实验，创建新目录；重新计算特征、清洗和训练，随后逐划分对比。只复用预训练权重不能被描述为复用了已训练分类器。
- **只比较或解释已有实验**：读取已有指标和证据，不自动重新训练。生成配对差值、原因说明和流程图。
- **当前抗皮肤衰老肽论文**：额外阅读 [论文专用配置](references/skinaging-profile.md)。其中的样本数、参数、种子和历史结论仅适用于这个公开版本，不作为其他论文的默认值或验收目标。

先检查工作区说明、Git 状态、作者仓库版本和已有运行目录。只有确实缺少论文、代码或数据位置，且不能从当前工作区确定时，才询问用户。

## 必须保留的科学区别

1. 作者原始代码和数据保持不变；修复在副本或执行脚本中进行，保留错误、修改内容和原因。
2. 原代码方案、论文固定参数方案、指标修正方案、独立清洗方案和无泄漏改进方案分别命名。不要把改进方案的成绩替换为原方法的成绩。
3. 不为接近论文数值而挑选种子、删样本、改变标签、缩小网格或调清洗阈值。明确记录缺失实现和新增假设。
4. 训练/测试身份、模型初始化和 CV 的随机状态分别记录。原实现没有固定的随机状态若被补上，应作为明确变化的实验方案。
5. 标准指标使用明确的正类和混淆矩阵顺序；保留作者打印指标的实际公式。公式不同的指标不能直接解释为性能差距。
6. 全量 refit 模型的输出一致性检查不算独立测试。重复运行稳定不等于论文严格复现，也不等于生物学有效。

## 实际执行

完整流程及证据要求见 [计算流程](references/workflow.md)。保留原有目录结构，已有可用脚本优先复用，不必重新搭建工程。

对当前论文，使用 `scripts/prepare_skinaging_run.py` 创建新的隔离目录。该工具只准备运行，不训练、不下载、不修改作者仓库，也不覆盖已有实验。它依赖工作区中已有的 `reproduction/` 执行脚本，不是其他论文的通用训练器。

```bash
# SKILL_DIR 是本 SKILL.md 所在目录；在目标工作区运行。
.venv/bin/python "$SKILL_DIR/scripts/prepare_skinaging_run.py" \
  --workspace . --run-id run_03_YYYY-MM-DD
```

阅读输出目录的 `run_plan.json` 和 `logs/path_isolation_only.diff`，再按计划中的命令执行。命令会运行完整流程，不传跳过 ESM 或 Notebook 的参数。记录开始/结束时间、退出码、阶段日志和最终验证结果。失败时先诊断并保留证据；不要不加说明地反复覆盖同一实验。

对任意两次具有本项目指标结构的运行，可用标准库工具配对：

```bash
.venv/bin/python "$SKILL_DIR/scripts/compare_metrics.py" \
  --run1 reproduction/runs/RUN_A/results/model_metrics.csv \
  --run2 reproduction/runs/RUN_B/results/model_metrics.csv \
  --output reproduction/comparisons/RUN_A_vs_RUN_B
```

该工具按 `experiment,model,seed` 配对，拒绝重复键、缺失行和非有限指标；不假定必须有131行，不比较运行时间为模型准确性，也不把两次重复运行当作独立统计样本。输出目录必须不存在。

指标一致性之外，还应按任务检查环境、数据/代码哈希、划分成员、特征、清洗集合、最佳参数及最终模型预测；方法见 [比较与验证](references/workflow.md#比较与验证)。
